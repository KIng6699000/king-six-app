Firebase Setup လမ်းညွှန်

  1. Firebase Console တွင် Project အသစ်ဖန်တီးပြီး Authentication → Email/Password ကို Enable လုပ်ပါ။
  2. Firestore Database ဖန်တီးပြီး Web App config ကို အောက်ပါ firebaseConfig နေရာတွင် ထည့်ပါ။
  3. Authentication ထဲတွင် Master နှင့် Agent အကောင့်များကို ကြိုတင်ဖန်တီးပါ။
  4. Firestore → users collection ထဲတွင် UID နဲ့တူသော document တစ်ခုစီ ဖန်တီးပါ။ Master အတွက် { role: "master", displayName: "Master Name" }၊ Agent အတွက် { role: "agent", displayName: "Agent Name" } ထည့်ပါ။
  5. အောက်ပါ Security Rules ကို Firestore → Rules ထဲသို့ ကူးထည့်ပြီး Publish လုပ်ပါ။

Firestore Security Rules

မှတ်ချက် — ဤဖိုင်သည် အသင်းအဖွဲ့၏ အထွေထွေ လုပ်ငန်းမှတ်တမ်းစနစ်ဖြစ်ပြီး ငွေကြေး၊ လောင်းကြေး သို့မဟုတ် လောင်းကစားလုပ်ငန်းဆောင်ရွက်ချက်များကို မစီမံပါ။ Production မတင်မီ Rules ကို စမ်းသပ်ပြီး Firebase App Check နှင့် သင့်တော်သော backup စနစ်ကို ထပ်မံဖွင့်ပါ။
